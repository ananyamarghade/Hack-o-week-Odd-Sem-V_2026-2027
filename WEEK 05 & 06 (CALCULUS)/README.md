# WEEK 5 & 6 — LINEAR ALGEBRA & CALCULUS

This repository contains the implementation of Linear Algebra and Calculus concepts covered during Hack-o-week Week 5 & 6.

## Topics Covered

### Linear Algebra
- Vectors
- Matrices
- Matrix Operations
- Matrix Addition and Multiplication
- Transpose
- Determinant
- Inverse
- Eigenvalues
- Eigenvectors
- Dot Product
- Vector Operations

### Calculus
- Functions
- Limits
- Derivatives
- Partial Derivatives
- Gradients
- Numerical Differentiation
- Optimization Concepts
- Integration

## Implementation

The concepts are implemented using Python and NumPy with numerical examples and computational demonstrations.

## Technologies Used

- Python
- NumPy
- Matplotlib
- Jupyter Notebook

## Objective

To develop a practical understanding of Linear Algebra and Calculus by implementing mathematical concepts computationally and visualizing numerical results where applicable.

## Key Findings

The implementation demonstrated how mathematical concepts can be translated into computational operations:

- Vector and matrix operations can be efficiently performed using NumPy arrays.
- Broadcasting allows operations between arrays of compatible but different shapes without explicit loops.
- Matrix multiplication can be used to represent transformations and relationships between vectors and matrices.
- Determinants and matrix inverses provide useful information about matrix properties and solvability.
- Eigenvalues and eigenvectors demonstrate important properties of matrix transformations.
- Derivatives describe the rate of change of a function at a given point.
- Numerical differentiation can approximate derivatives computationally.
- Partial derivatives allow the rate of change of multivariable functions to be studied with respect to individual variables.
- Gradients combine partial derivatives to represent the direction of steepest increase of a function.
- Visualization helps demonstrate mathematical behaviour such as functions, derivatives and gradients.

## Outcome

The project provides a practical computational understanding of Linear Algebra and Calculus by implementing mathematical concepts using Python and NumPy and visualizing their behaviour where applicable.
