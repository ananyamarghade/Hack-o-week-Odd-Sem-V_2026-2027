# Hack-o-week-Sem-V

A collection of practical implementations and projects completed as part of the Semester V Hack-o-week program.

---

## 📅 Week 1 & Week 2 — Web Development

### Project: Personal Expense Tracker

### Tasks Implemented
- Built a responsive frontend using HTML, CSS, and JavaScript
- Developed a REST API using Node.js
- Implemented CRUD operations for expense management
- Added expense search and category-based filtering
- Added automatic spending summaries
- Implemented form validation and responsive UI

### Real-World Application
The application provides a simple way to record and manage daily expenses while giving users an overview of their spending behaviour.

### Key Outcomes
- Demonstrated communication between a frontend and REST API
- Implemented complete CRUD-based data management
- Used filtering and aggregation to provide useful spending summaries
- Built a practical application around an everyday financial-management problem

## 📅 Week 3 & Week 4 — Python & Data Analysis

### Project: Indian Commodity Price Analysis

### Tasks Implemented
- Implemented Python functions and Object-Oriented Programming
- Used list and dictionary comprehensions
- Implemented NumPy arrays, broadcasting, and vectorized operations
- Performed data cleaning and preprocessing using Pandas
- Handled missing and inconsistent data
- Used filtering, sorting, merging, GroupBy, and aggregation
- Created statistical and visual analyses using Matplotlib and Seaborn

### Real-World Problem
Everyday commodity prices can vary significantly across locations and over time. Understanding these variations can help identify price volatility, regional differences, and periods of unusual price changes.

### Analysis Performed
- Compared prices across different commodities
- Studied regional price differences
- Analysed price variation over time
- Measured commodity-wise price volatility
- Investigated price distributions and outliers
- Examined missing-value patterns in the raw dataset
- Used statistical measures to compare price behaviour

### Key Findings
- Commodity prices show noticeable variation across locations and time periods.
- Different commodities exhibit different levels of price volatility.
- Regional comparisons reveal significant differences in the prices of everyday commodities.
- Time-based analysis highlights changing price patterns and periods of increased variation.
- Statistical analysis provides a clearer understanding of typical prices, spread, and unusual observations.

### Real-World Outcome
The analysis demonstrates how raw commodity-price data can be transformed into useful information for understanding regional price differences and identifying commodities or periods that require closer monitoring.

## 📅 Week 5 & Week 6 — Linear Algebra & Calculus

### Project: Computational Linear Algebra & Calculus

### Tasks Implemented
- Implemented vectors and matrices using NumPy
- Performed matrix addition, multiplication, and transpose operations
- Implemented dot products and vector operations
- Calculated determinants and matrix inverses
- Computed eigenvalues and eigenvectors
- Implemented mathematical functions computationally
- Explored derivatives and numerical differentiation
- Implemented partial derivatives
- Calculated gradients
- Visualized mathematical functions and numerical behaviour

### Real-World Relevance
Linear Algebra and Calculus form the mathematical foundation of many areas of computer science, including machine learning, computer vision, optimization, graphics, and data science.

### Analysis & Implementation
- Used vectors and matrices to represent and manipulate numerical data
- Explored matrix transformations using eigenvalues and eigenvectors
- Used numerical differentiation to study rates of change
- Used partial derivatives to analyse multivariable functions
- Used gradients to identify directions of greatest change
- Visualized mathematical behaviour to connect theoretical concepts with computation

### Key Outcomes
- Developed a computational understanding of fundamental Linear Algebra operations.
- Demonstrated how matrix properties can be explored programmatically.
- Connected derivatives and gradients with numerical computation.
- Used visualization to make mathematical behaviour easier to interpret.
- Established mathematical foundations relevant to future data science and machine learning applications.
