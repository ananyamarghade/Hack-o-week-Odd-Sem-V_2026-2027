## Project

### Household Energy Consumption Prediction and Classification

A real-world machine learning project based on household appliance energy consumption data.

The project uses environmental and household-related measurements to predict energy consumption and classify observations into different consumption levels.

## Tasks Implemented

- Loaded and explored a real-world energy consumption dataset
- Performed data preprocessing and feature preparation
- Implemented Linear Regression
- Implemented Polynomial Regression
- Implemented Ridge Regression
- Implemented Lasso Regression
- Compared regression model performance
- Derived a high-energy-consumption classification target
- Implemented Logistic Regression
- Implemented K-Nearest Neighbors (KNN)
- Evaluated classification models using multiple performance metrics
- Visualized actual and predicted values
- Analysed feature coefficients and model behaviour

## Real-World Problem

Household energy consumption varies according to time, temperature, humidity, and other environmental conditions.

Predicting energy consumption can help understand household energy usage patterns and identify periods of unusually high consumption.

## Analysis Performed

- Analysed daily and hourly energy consumption
- Compared energy consumption across weekdays and weekends
- Studied temperature and energy consumption relationships
- Analysed humidity and energy consumption
- Examined indoor and outdoor temperature patterns
- Investigated monthly consumption trends
- Compared actual and predicted energy consumption
- Compared regression models using standard evaluation metrics
- Analysed high-consumption observations using classification models
- Compared Logistic Regression and KNN performance

## Key Findings

- Household energy consumption varies significantly across different times of the day.
- Energy usage shows noticeable differences between weekdays and weekends.
- Temperature and humidity provide useful information for analysing energy consumption patterns.
- Regression models provide different levels of prediction performance depending on model complexity and regularization.
- Polynomial Regression can capture nonlinear relationships in the data.
- Ridge and Lasso Regression demonstrate the effect of regularization on model coefficients.
- Logistic Regression and KNN provide different approaches for classifying high-consumption observations.
- Multiple evaluation metrics provide a better comparison of classification models than accuracy alone.

## Real-World Outcome

The project demonstrates how regression and classification techniques can be applied to real-world household energy data to predict energy consumption and identify high-consumption conditions.
