## Project

### Indian Commodity Price Analysis

A real-world data analysis project based on retail prices of commodities in India.

The analysis explores:
- Commodity price trends
- Price variations across locations
- Commodity-wise comparisons
- Seasonal patterns
- Price volatility
- Data quality and missing values
- Statistical patterns and relationships
